# AI Memory — KPA EMC² Web Portal

> Folder ini adalah **memori hidup** untuk semua AI Assistant yang bekerja di proyek ini.
> **Wajib dibaca sebelum mengambil aksi apapun** dalam sesi baru.

## Cara Membaca Folder Ini

Baca file-file berikut secara berurutan di awal sesi:

| # | File | Isi | Update |
|---|------|-----|--------|
| 1 | [`overview.md`](./overview.md) | Gambaran umum proyek, stack, domain, struktur direktori | Jarang (hanya jika stack berubah) |
| 2 | [`progress.md`](./progress.md) | Status sprint dan daftar fitur terkini | **Setiap sesi** |
| 3 | [`decisions.md`](./decisions.md) | Keputusan teknis penting yang pernah diambil (ADR) | Saat ada keputusan baru |
| 4 | [`gotchas.md`](./gotchas.md) | Bug, jebakan, quirks yang sudah ditemukan | Saat menemukan masalah baru |
| 5 | [`conventions.md`](./conventions.md) | Naming, format, struktur kode spesifik proyek ini | Saat konvensi ditambah/diubah |
| 6 | [`rules.md`](./rules.md) | Aturan hard rules dan larangan untuk semua AI | Jarang (hanya jika aturan berubah) |

## Cara Update

AI wajib **memperbarui `progress.md`** di akhir setiap sesi kerja yang signifikan.
File lainnya diperbarui hanya saat ada perubahan relevan pada konten masing-masing.
